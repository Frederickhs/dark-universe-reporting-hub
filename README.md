# Dark Universe Reporting Hub

The Dark Universe Reporting Hub is a Windows desktop launcher that runs three independent Python reporting projects from one interface.

The Hub provides:

- One central application for all three reports
- Individual report buttons
- A Run All Reports option
- Input and output folder shortcuts
- Central Hub logging
- Combined success and failure summaries
- Continued processing when one report fails
- Future Windows EXE packaging

The Hub is an orchestrator only. It does not contain or replace the business logic of the three reporting projects.
